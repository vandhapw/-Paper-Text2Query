# SoftwareX — Conference Guidelines for Submission

## Journal Overview
- **Journal:** SoftwareX (Elsevier)
- **ISSN:** 2352-7110
- **Article Type:** Original Software Publication
- **Open Access:** Yes (APC: USD 1,560)

## Mandatory Format Requirements

### Word Limit
- **Maximum 3,000 words** (excluding title, authors, affiliations, references, metadata tables)
- Including: abstract, running text, captions, footnotes
- **Maximum 6 figures**

### Title Format
- Must follow pattern: "Title (SoftwareName: Then a short title)"
- Example: "A natural language query system for IoT sensor data (Text2Query: A four-stage pipeline for sensor data querying)"

### Abstract
- Maximum 250 words
- Concise and factual, stands alone
- No references or non-standard abbreviations

### Keywords
- 1 to 7 keywords, written in English

### Mandatory Sections (in order)
1. **Motivation and significance** — Scientific background, the problem solved, contribution to discovery, experimental setting, and related work
2. **Software description** — Subdivided into:
   - (a) Software architecture (overview, pictorial diagram)
   - (b) Software functionalities
   - (c) Sample code snippets (optional)
3. **Illustrative examples** — At least one example; optionally one MP4 video
4. **Impact** — The main section. New research questions enabled, improvements to existing approaches, changes to user practice, breadth of adoption, commercial use
5. **Conclusions** — Mandatory summary

### Code Metadata Table (Mandatory)
Must include:
| # | Field |
|---|-------|
| C1 | Current code version |
| C2 | Permanent GitHub link |
| C3 | Legal Code License (OSI-approved) |
| C4 | Code versioning system |
| C5 | Software code languages, tools, services |
| C6 | Compilation requirements, operating environments & dependencies |
| C7 | Link to developer documentation/manual |
| C8 | Support email for questions |

### Software Repository Requirements
- **GitHub only** (no GitLab or other platforms)
- Must include: README.md, LICENSE.txt, source code in repo/src/
- Must be open-source under OSI-approved license

### References Style
- Numbered in square brackets: [3,6]
- More than 6 authors: first 6 followed by "et al."
- Use `elsarticle-num` bibliography style

### CRediT Author Contributions
Must declare using CRediT taxonomy roles

### Generative AI Declaration
Must declare AI use at end of manuscript before references

### Figures
- Maximum 6 figures
- Minimum 300 DPI for halftones, 1000 DPI for line drawings
- Submit as separate files (Figure_1, Figure_2, etc.)
- All figures must have captions

### Submission
- Use SoftwareX LaTeX template (elsarticle class)
- Upload PDF as *Manuscript field
- Upload .zip with all source files (.tex, figures, bibliography)
- Submit via Editorial Manager: https://www.editorialmanager.com/softx
